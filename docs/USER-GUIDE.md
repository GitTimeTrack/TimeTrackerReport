# 操作ガイド

## 最初の操作

1. 配布されたZIPを展開し、`TimeTrackerReport.exe`を起動します。古い版を起動中の場合は、トレイのメニューから終了しておきます。
2. 初回は画面上部に導入ガイドが表示されます。「タスク追加」で作業を登録し、「開始」で計測します。
3. 終了時は「一時停止」を押し、編集画面または一覧内の編集から詳細メモを保存します。ガイドは完了すると閉じます。
4. 「日報をつくる」からコピーやTXT出力を行います。

ガイドは最初の最大3回の表示までです。同じ起動中のトレイからの再表示は回数を増やしません。閉じても、設定の「導入ガイドをもう一度表示」で最初から確認できます。表示回数と完了状態はPC内の `onboarding.json` に保存し、作業のJSONバックアップとは分けて管理します。

## 現在のバージョンを確認する

設定の「バージョン情報」で現在のアプリの版を確認できます。表示は実行中のアプリ本体から取得するため、ネットワークへの接続は不要です。
