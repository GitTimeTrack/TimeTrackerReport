# TimeTrackerReport — Windows ネイティブ版

C# / .NET 10 / WPFで新しく実装した、作業計測と日報作成のWindowsアプリです。画面はXAMLによるネイティブUIで、ブラウザー・WebView・Pythonサーバーを使用しません。

## 使い始める

対応環境はWindows 10 / 11です。標準の配布対象は64bit（x64）です。

1. GitHubの **Actions → Windows native** で成功した実行を開き、下部の **Artifacts → TimeTrackerReport-win-x64** をダウンロードします（GitHubへのログインが必要です）。
2. ダウンロードしたZIPを展開します。
3. `TimeTrackerReport.exe` を起動します。.NETランタイムの別途インストールは不要です。
4. 「タスク追加」で作業を登録して「開始」を押します。0hの予定も登録できます。

現時点の配布物はコード署名をしていません。Windows環境によっては起動時に発行元を確認する画面が表示されます。

## 最初の版でできること

- 今日・次日のタスクの追加、編集、削除、並べ替え、検索、予定の引き継ぎ
- 1タスクずつの計測、実績の後からの補正、10秒ごとの保存、異常終了からの復元
- トレイ常駐、トレイから開始・停止・切替、最前面のミニタイマー
- 長時間計測・未計測の通知、通知クリックによる画面表示
- 入力がない時間・画面ロック・スリープの検知と一時停止
- 復帰時に「離席時間を除外して再開」「含めて再開」「停止したまま」を選択
- 日報の下書き、コピー、TXT出力、日・週・月のプロジェクト別分析とCSV出力
- TXTテンプレートからのタスク追加、JSONのバックアップ・復元、旧Web版JSONの移行
- ライト／ダーク／Windows設定に合わせるテーマ、サインイン時のトレイ起動

通知はWindowsのトレイ通知を使います。Windowsの通知設定や集中モードによって表示が抑制されることがあります。通知内の専用停止ボタンやポモドーロ、繰り返し予定、終業時刻に合わせた日報通知は今後の拡張対象です。

## トレイとショートカット

- `Ctrl + Alt + T`：選択タスクの開始／一時停止（未選択時は先頭タスク）
- `Ctrl + Alt + Space`：メイン画面を表示
- トレイの時計アイコンをダブルクリック：画面を表示
- トレイを右クリック：タスク切替、ミニタイマー、終了

ショートカットが他のアプリと競合した場合は画面下部に表示します。デフォルトでは閉じるボタンでトレイに移動します。アプリを完全に終了するにはトレイの「終了」を選択してください。

離席判定はWindowsの最後の入力時刻を使います。アプリ名や画面内容は記録しません。ロック中やスリープ中もアプリは起動していますが、既定では計測を一時停止します。日付をまたいだ計測は前日の午前0時で停止します。終了・クラッシュ中の時間は自動加算しません。

## データと旧版からの移行

保存先はユーザーごとの `%LOCALAPPDATA%\TimeTrackerReport\tracker.db` です。SQLiteのトランザクションで保存し、起動時にはその日の自動バックアップを作成します。起動時バックアップは直近14個を残します。復元前のバックアップは別途保存します。

旧Web版を使っている場合は、**移行前に旧版の計測を止めて全データJSONをエクスポート**してください。

1. ネイティブ版の「設定とデータ → JSONを移行・復元」を選びます。
2. 旧版のバックアップJSON、または `data/tracker_data.json` を指定します。
3. 復元確認を承認します。タスク、日別履歴、次日の予定、通知設定を移行します。

初回起動時に実行ファイルの隣の `data/tracker_data.json` が見つかった場合も移行を案内します。元のJSONは変更しません。旧版のブラウザー内保存を直接読むことはできないため、JSONで移行してください。復元時は計測を停止し、異常な内容は保存前に拒否します。Windowsの自動起動設定はJSON復元では変更しません。

保存に失敗した場合は画面下部に「未保存」と表示します。「設定とデータ → JSONバックアップ」から、別の書き込み可能なフォルダーへ出力できます。保存失敗時は通常の終了を中止してデータ保護を促します。

SQLiteファイルを手動で移す場合は、アプリを完全に終了してから行ってください。稼働中のコピーにはWALが関わるため、通常はJSONバックアップを使ってください。

## ソースからビルドする

Windowsに [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) をインストールします。Visual Studioを使う場合はWPFを含む.NETデスクトップ開発環境が必要です。

```powershell
dotnet run --project desktop/TimeTracker.Windows/TimeTracker.Windows.csproj
```

リポジトリ直下の `日報アプリ起動.bat` も、ビルド済みのネイティブ版または.NETプロジェクトを起動します。自動起動の登録はビルド済みのexeから設定してください。

テストと配布用ZIPの生成：

```powershell
./scripts/publish-windows.ps1
# ARM64向けの場合
./scripts/publish-windows.ps1 -Runtime win-arm64
```

出力先は `artifacts/TimeTrackerReport-win-x64/` と、そのZIPです。ZIPはフォルダーごと展開してください。SQLiteなどのネイティブライブラリは実行時に.NETの管理する一時フォルダーに展開されますが、ユーザーデータはLocalAppDataに保持します。

## 検証と構成

```powershell
dotnet test desktop/TimeTracker.Core.Tests/TimeTracker.Core.Tests.csproj -c Release
dotnet build desktop/TimeTracker.Windows/TimeTracker.Windows.csproj -c Release
```

- `TimeTracker.Core`：計測、日付、JSON移行・検証、SQLite保存・バックアップ、日報・集計
- `TimeTracker.Windows`：WPF画面、トレイ、Windows連携、ショートカット、自動起動
- `TimeTracker.Core.Tests`：実SQLiteを使うロールバック・バックアップ、移行、タイマー等の回帰テスト
- `.github/workflows/windows-native.yml`：Windowsでテスト・配布ビルド・起動テストを実行してZIPを保存

Windowsでの起動テストは配布exeの `--smoke-test` を使います。一時保存先だけを使い、4画面、タスク編集画面、タイマー、トレイ、ミニタイマー、テーマ、SQLite保存を確認して終了します。手動確認項目は [Windows確認リスト](desktop/WINDOWS-VALIDATION.md) にあります。

旧Web版の `app.js`、`index.html`、Pythonランチャー、`tests/` は移行と回帰確認のため残しています。新しいWindows版からは使用しません。旧Python向けの `build_exe.py` ではなく、配布には上記PowerShellスクリプトを使用してください。

### 予定一覧の操作

本日の作業と次日の予定は、件数付きのタブで切り替えます。各一覧を画面いっぱいの高さでスクロールでき、予定・実績時間を同じ列で比較できます。長いタスク名はマウスを重ねると全文、タスク欄ではメモも確認できます。

左端の「⠿」をドラッグすると、表示される挿入線の位置へ並べ替えられます。一覧の上下端では自動スクロールします。選択した行は `Alt + ↑ / ↓` でも移動できます。検索中は順序の混乱を防ぐため、検索をクリアしてから並べ替えてください。

ひな型のTXTファイルは、ワークスペース上部の「ひな型を読み込む」から直接読み込めます。確認後、既存のタスクを残して本日・次日に追加します。

本日・次日の各一覧には、その日の全作業の予定合計・実績合計を表示します。検索中も全件の合計です。次日の予定は通常まだ計測していないため、実績合計は0hです。

設定の「予定時間を超えたら通知と音で知らせる」をONにして保存すると、計測中の累積実績が予定時間を超えたときに通知と警告音が出ます。初期値はOFFです。0hの予定は計測開始後に通知されます。同じ予定時間では停止・再開しても繰り返し通知しません。実績が予定以下に戻るか予定時間を変更すると再判定し、アプリの再起動時は通知済み状態をリセットします。

### カラーテーマ

設定画面の「外観」から、ディープネイビー・ティール・スレート・プラムを選べます。「明暗」は色とは独立して、Windowsに合わせる／ライト／ダークを指定します。新規利用・色設定のない旧データではディープネイビーを使用し、既存の明暗・通知設定や作業データは維持します。

選択するとアプリ全体へプレビューされます。「設定を保存」で確定し、次回起動後も保持します。「配色の変更を取り消す」で保存済みの色と明暗に戻せます。変更したまま画面を移動・閉じる場合は、保存・取り消し・キャンセルを選べます。プレビューは自動保存の対象に含めません。

### 削除を元に戻す

作業・予定を削除すると、画面下部に削除対象と「元に戻す」が表示されます。復元できるのはアプリ起動中の直近1件です。次の削除で復元対象が置き換わり、アプリ終了やJSONの復元時には履歴を消去します。

日付を切り替えた後でも、元の日付・一覧の位置へ復元します。プロジェクト・予定時間・実績・メモは保持され、計測中だったタスクも停止状態で戻ります。ほかに計測中のタスクがある場合は、その計測を継続します。

### 前日の作業から追加・一覧から複製

ワークスペースの「前日の作業から追加」で、前日の作業から必要な項目を選べます。「一覧から複製…」は、表示中の本日／次日タブの全件を候補にします。登録先の日付と作業／予定、メモを引き継ぐかを選び、確認して追加します。元の記録は残り、複製した項目の実績は0hになります。別の日付へ追加した場合は、日付を切り替えて確認できます。

### 一覧で時間・メモを編集

予定・実績の時間ボタンをクリックすると、行の中に編集欄が開きます。詳細メモの「メモを一覧で編集」からも開けます。時間欄はEnterで保存、Escで取り消し。メモ欄は改行入力でき、「保存」で確定します。次日の予定の実績時間は編集対象にしません。

未確定の入力は計測更新で上書きされません。日付・画面・本日／次日タブ・検索を切り替える際は、保存／取り消し／キャンセルを選べます。並べ替えは編集を完了してから操作してください。

### 導入ガイドとバージョン表示

初回から最大3回、メイン画面上部に「開始→停止・メモ保存」の導入ガイドを表示します。閉じることができ、設定の「導入ガイドをもう一度表示」からいつでも確認できます。トレイ起動ではガイドのために画面を開かず、初めてメイン画面を表示したときに案内します。

設定の「バージョン情報」で現在のアプリの版を確認できます。操作手順は [操作ガイド](docs/USER-GUIDE.md) を参照してください。ビルド時に版を指定する場合は `./scripts/publish-windows.ps1 -Version 1.2.0` を使えます。
