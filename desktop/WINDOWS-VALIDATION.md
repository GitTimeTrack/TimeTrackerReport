# Windows実機での確認

CIの起動テストに加え、Windowsの通知・電源・入力に関わる以下を実機で確認してください。

- [ ] ZIP展開後、Pythonや.NETランタイムを追加せずに起動できる。
- [ ] 画面4種類、編集ダイアログ、検索を日本語入力で操作できる。キーボードのTab移動とEnter保存が使える。
- [ ] Windows表示倍率100% / 150% / 200%、ライト／ダーク、高DPIの複数モニターで内容を読める。
- [ ] 0h、空欄の1h、小数、負数の拒否を追加・編集で確認できる。
- [ ] 開始・停止・タスク切替・実績補正後に計測が正しく続く。
- [ ] トレイ常駐中に計測・通知が動き、ダブルクリックで画面に戻れる。
- [ ] ショートカットが動く。他アプリとの競合時は状態が表示される。
- [ ] ミニタイマーが最前面に表示され、開始・停止が同期する。
- [ ] 未計測5分・長時間15分で通知され、通知クリックで画面が開く。
- [ ] 離席5分後、復帰時に除外／含める／停止を選べ、それぞれ実績が合う。
- [ ] Win+Lとスリープの間は停止し、復帰後に確認が出る。確認をキャンセルすると停止したままになる。
- [ ] Windows終了／再起動で保存される。強制終了後も最終チェックポイントまで復元し、停止中の時間が増えない。
- [ ] 日付をまたぐと前日午前0時で停止し、今日への移動と予定の引継ぎができる。
- [ ] 二重起動時に既存画面が表示され、2つのプロセスが同じデータを書き換えない。
- [ ] 自動起動の有効・無効がユーザーのRunキーに反映され、サインイン後はトレイで起動する。
- [ ] 旧版のJSONで履歴・予定・0h・メモ・通知設定を移行でき、元JSONが残る。
- [ ] 不正なJSON復元で現在のタスクと計測状態が変わらない。
- [ ] JSON復元前のDBバックアップと、直近14個の起動時バックアップが保存される。
- [ ] 容量／権限による保存失敗が「未保存」と表示され、別フォルダーにJSONを救出できる。
- [ ] TXT・CSV・JSONを再読込し、日本語、引用符、複数行メモ、日付、時間が一致する。

このリストは手動確認の手順です。チェックがない項目を検証済みとして扱わないでください。
